Data source configuration

Настройки источника

В оригинальном Excel-файле путь к папке задаётся на листе «Настройки». Здесь — браузерная модель: выбери папку с демонстрационными CSV, затем нажми Refresh All. Браузер не может читать произвольный путь без выбора файлов.

Соответствие договора клиентскому коду

Формат CSV: ClientCode,Month,Method,Quantity (запятая, десятичная точка). Например CLIENT-A,2026-08,REG-A,100. Договор определяется по клиентскому коду, затем метод сопоставляется по договору. Записи вне периода и несопоставленные записи не попадают в расчёты; последние показаны в контроле источника и в разделе методов. Все файлы обрабатываются локально; не выбирай рабочие отчёты компании.

Модель обработки

Папка отчётов → объединение записей → сопоставление клиентского кода с договором → сопоставление метода отчёта с договорным методом → расчёт факта и лимитов → обновление дашбордов.

Контроль источника

Contract parameters

Тарифы и договорные объёмы

Выбери договор, измени цену или лимит и нажми «Применить». Показатели пересчитываются для этого договора; фактические объёмы остаются неизменными.

Изменения действуют только в текущем сеансе страницы. Исходные рабочие файлы не используются.

Method mapping

Соответствие методов

Для выбранного выше договора задай, к какой договорной позиции относятся коды методов в отчёте. Несколько исходных кодов могут иметь один договорный метод; цены и лимиты берутся из этой позиции, а объёмы суммируются.

Демонстрационные обозначения не являются кодами компании. Удаление соответствия переводит записи в список несопоставленных; точное совпадение с договорным методом принимается автоматически, если отдельное соответствие не задано.

Project overview

Задача и решение

Задача: адаптировать существующий инструмент контроля бюджета для участка с несколькими самостоятельными договорами, разными тарифами и договорными объёмами.

Решение в Excel: справочник договоров и клиентских кодов, параметры периода и источника отчётов, тарифы и сопоставление методов по договорам, контроль бюджета и методов по каждому договору, сравнение освоения и выбор отчётного месяца. Обработка данных через Power Query.

Практическая ценность: централизованный контроль нескольких договоров без ручного построения отдельных отчётов для каждого.

В браузере расчёт и локальная загрузка CSV реализованы на JavaScript. Это демонстрация принципа, а не оригинальный Power Query-процесс; формат CSV, ручное применение тарифов и расчётный бюджет добавлены для наглядности.
