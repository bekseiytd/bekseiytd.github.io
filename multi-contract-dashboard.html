Настройки источника

В оригинальном Excel-файле путь к папке задаётся на листе «Настройки». Здесь — браузерная модель: выбери папку с демонстрационными CSV, затем нажми Refresh All. Браузер не может читать произвольный путь без выбора файлов.

Формат CSV: Contract,Month,Method,Quantity (разделитель — запятая, десятичный знак — точка). Коды договоров C-001…C-004, месяцы 2026-08…2026-12, методы REG-01, PREP-01, AN-01, QC-01. Все файлы обрабатываются локально; не выбирай рабочие отчёты компании.

Модель обработки

Папка отчётов → объединение записей → сопоставление договора и метода → расчёт факта и лимитов → обновление дашбордов.

Выбери договор, измени цену или лимит и нажми «Применить». Показатели пересчитываются для этого договора; фактические объёмы остаются неизменными.

Project overview

Задача и решение

Задача: адаптировать существующий инструмент контроля бюджета для участка с несколькими самостоятельными договорами, разными тарифами и договорными объёмами.

Решение в Excel: отдельные параметры источника отчётов и тарифов, контроль бюджета и методов по каждому договору, сравнение освоения и выбор отчётного месяца. Обработка данных через Power Query.

Практическая ценность: централизованный контроль нескольких договоров без ручного построения отдельных отчётов для каждого.

В браузере расчёт и локальная загрузка CSV реализованы на JavaScript. Это демонстрация принципа, а не оригинальный Power Query-процесс; формат CSV, ручное применение тарифов и расчётный бюджет добавлены для наглядности.
